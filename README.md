# Fiadito

Libreta de fiado para tienditas. Cobra lo que fías.

- Apunta fiados y abonos en segundos, con teclado tipo calculadora.
- Manda la cuenta o el recibo a tus clientes por WhatsApp.
- Ve quién te debe más y quién está atrasado.
- Funciona sin internet y se instala en el celular.

Los datos se guardan solo en el celular de cada tienda; no se envían a ningún servidor.

**Usarla:** https://lpena6952-wq.github.io/fiadito/
